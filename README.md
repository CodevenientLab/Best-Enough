# Best Enough Driving School

Premium React + Vite marketing site for Best Enough Driving School.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Project notes

- Business facts, prices, packages, locations and FAQs live in `src/data/business.js`.
- WhatsApp links are generated in `src/utils/whatsapp.js`.
- Real client/team photography is stored in `src/assets/photos/`.
- No testimonials, pass rates, qualifications or other unsupported claims have been invented.
- Package pass-guarantee language is presented with a terms-and-conditions note because the supplied flyer did not provide the terms.
